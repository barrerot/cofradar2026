# Chip de alteración

Señala una alteración de la cofradía que se superpone a su fase: Retraso, Adelanto, Cambio de recorrido, Incidencia, Interrumpida, Regreso anticipado.

## Qué aporta quien lo usa
- `data-alteracion`: `incidencia` · `interrumpida` · `regreso_anticipado` · `cambio_recorrido` · `retraso` · `adelanto`.
- Minutos para retraso/adelanto (cifras tabulares, signo + / −).
- En densidad compacta: solo la más grave + contador «+N» con el resto.

## Reglas
- Orden: incidencia / interrumpida / regreso anticipado > cambio de recorrido > retraso / adelanto.
- Nunca se oculta una alteración por falta de espacio; se abrevia quitando la palabra genérica, nunca la cifra (abreviaturas exactas NO DEFINIDAS).
- Familias: retraso, adelanto, cambio de recorrido → warn; incidencia, interrumpida, regreso anticipado → alert.
- Iconos Phosphor provisionales.
